# Muslim Companion — UI/UX Design

**Muslim Companion** is a mobile app UI/UX design project created in Figma to provide a simple, clean, and user-friendly experience for daily Islamic activities.

The design brings essential features together in one interface, including prayer times, Qibla direction, an Islamic calendar, prayer reminders, and a dedicated **Qaza Prayer Tracker** for managing missed prayers.

The focus is on intuitive navigation, consistent layouts, readable typography, and a visually appealing interface that makes Islamic utilities easy to access.

**Tools:** Figma  
**Project Type:** Mobile App UI/UX Design
